# Matriotic Studios — Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Scroll progress bar (`src/components/ScrollProgress.tsx`) — a 2px gold `scaleX`
  bar driven by a passive scroll listener, hidden under
  `prefers-reduced-motion`.
- Animated stat counters (`src/components/motion/Counter.tsx`) — count-up via
  `useInView` + `requestAnimationFrame` with an `EaseOutExpo` curve, used on the
  homepage stats block.
- Shared desktop gate `useDesktop` (`src/hooks/useViewport.ts`) — single source
  of truth for the "viewport ≥ 768px" check, replacing three duplicated copies.
- Centralized spring constants (`src/lib/springs.ts`) — `HERO_BACKDROP`,
  `ORBIT_RINGS`, `WIRE_PRISM`, `PARALLAX`, `CASE_STUDY` replace scattered
  stiffness/damping magic numbers.
- Brand placeholder artwork for every image the site references
  (`scripts/generate-images.mjs` — sharp + SVG, WebP q80, drop-in replaceable).

### Changed

- **Fonts** — switched from `next/font/local` (missing files, build-blocking)
  to `next/font/google` (`Playfair_Display` + `Inter`, latin subset,
  `display: swap`, `preload: true`). Zero CLS via size-adjusted fallbacks.
- **Images** — every `<Image>` now carries `placeholder="blur"` with a shared
  base64 `blurDataURL` for instant LCP and zero CLS.
- **Smooth scroll** — in-page anchor clicks now use a **non-passive** listener
  (the handler calls `preventDefault`, which passive listeners silently drop).
- **Header hide/show** — desktop scroll listener is now created **once** (the
  `lastScrollY` tracking moved from state into a ref), and the dead
  `headerHidden` state was removed.
- **Theme toggle** — initial theme is read in a lazy `useState` initializer
  instead of inside an effect, and `current()` is SSR-safe.
- **Preloader/Hero** — preloader-done state is read in a lazy initializer rather
  than set synchronously inside an effect.
- **Navigation** — the mobile menu now closes on link click instead of via a
  standalone effect.
- **Caching** — `next.config.ts` now serves `/images/*` and `/_next/static/*`
  with `Cache-Control: public, max-age=31536000, immutable`.
- **Dead CSS removed** — `.reveal-section` / `.reveal-stagger` / `.is-visible`
  blocks were confirmed unreferenced by any component (the site uses
  `motion/react`'s `Reveal`/`Stagger`/`SplitHeading` instead).

### Fixed

- SSR crash on every page: `ThemeToggle` read `document` at module-evaluation
  time. Now guarded with `typeof document === "undefined"`.
- Smooth-scroll of in-page anchor links was silently broken by the
  `{ passive: true }` listener.
- SiteHeader re-created its scroll listener on every scroll tick.

## Portfolio section updates (per latest request)

- **lib/projects.ts** — shortened all six project descriptions to 2–3 lines
  (~180–220 characters) as specified.
- **src/components/portfolio/CaseStudy.tsx** — restored the original
  alternating left/right layout (image on one side, text on the other) and
  made **only the image area** clickable (wrapped in an `<a>` tag opening the
  live URL in a new tab). Added a desktop‑only hover effect: thumbnail scales
  1.03, thin gold border glow, and a faint arrow icon (↗) fades in top‑right.
  The text block uses `line-clamp-4` on desktop and `line-clamp-3` on mobile
  for the description. All other structure, styling, and class names are
  unchanged.
- Six thumbnail WebP images (`work-aeris.webp`, `work-lia.webp`,
  `work-arkhe.webp`, `work-flowline.webp`, `work-iz.webp`,
  `work-workoutclub.webp`) were generated via
  `scripts/generate-images.mjs` (sharp + SVG, 1200×800, WebP q80, each
  <60 KB).
